## App-Review-Informationen (Notes for Review, Englisch)

```
Liftfolio is a fully offline strength training log. No login or account is required, and no data leaves the device.

On first launch a short intro appears (it can be skipped). The bear mascot "speaks" with a short synthesized sound; it follows the silent switch.

Native features:
- Data is stored as a file on the device (works offline, included in device backups).
- Haptic feedback when logging a set and on personal records.
- Optional local reminder notifications: Settings tab → Reminder (asks for permission).
- Export via the iOS share sheet and import from the Files app: Settings tab → Data.

Quick test: Exercises tab → Bench Press → enter 80 kg, 5 reps → Log. Then 85 kg, 5 reps → Log (new record with haptic feedback). The Stats tab then shows the strength charts.
```
